# Plan

## Phase 1

Define the board model and storage.

1. choose the board file location under `.openscribe`
2. define the note, link, and group schema
3. define how promotion targets are represented

## Phase 2

Build basic CLI board management.

1. add board creation and listing commands
2. add note creation and listing commands
3. add link creation and removal commands
4. add group assignment commands

## Phase 3

Build basic board review experience.

1. add a terminal friendly board viewer or mode
2. show notes, groups, and links clearly
3. keep navigation simple and keyboard friendly

## Phase 4

Build promotion into manuscript structure.

1. define promotion targets such as part, chapter, or scene stub
2. create manuscript files from selected board notes
3. preserve clear traceability from board note to manuscript artifact

## Phase 5

Document and validate the feature.

1. add tests for board storage and promotion behavior
2. update README with board workflow guidance after implementation
3. confirm board usage does not interfere with compile or binder behavior
