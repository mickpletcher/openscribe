# Spec 002

Name: Board Mode

Status: Draft

Purpose:

This spec package defines a lightweight planning board for `openscribe`.

The goal is to support freeform brainstorming inside the same writing project without turning the app into a full visual diagram tool.

Files in this package:

1. `requirements.md`
   What must be true when this phase is complete
2. `spec.md`
   Scope, constraints, interfaces, and success criteria
3. `plan.md`
   Execution order
4. `tasks.md`
   Concrete implementation and validation checklist
