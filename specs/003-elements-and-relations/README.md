# Spec 003

Name: Elements and Relations

Status: Draft

Purpose:

This spec package defines structured tracking for characters, settings, items, and their relationships inside `openscribe`.

The goal is to give writers a clear system for manuscript entities and where they appear, without turning the project into a database heavy app too early.

Files in this package:

1. `requirements.md`
   What must be true when this phase is complete
2. `spec.md`
   Scope, constraints, interfaces, and success criteria
3. `plan.md`
   Execution order
4. `tasks.md`
   Concrete implementation and validation checklist
